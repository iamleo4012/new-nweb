## Mobile redesign of houseware.html — final plan

### Guiding principle
**The desktop page adapted for phones** — not a new design. Reuse the existing imagery, typography (font-headline Manrope / font-body Inter), colour palette (primary `#000308`, secondary `#825335`, primary-container, on-primary-container), cards, and composition. Only sizing/spacing/layout shift for the small screen.

### Scope reality
`houseware.html` is a category landing page (hero + 3 category bubbles + 3 magazine sections with image teasers). No product grid/sort/filter exists — I won't invent them. The floating Filter button is non-functional → **hide it on mobile**.

### Approach
One scoped `<style>` block (`@media (max-width: 767px)` overrides) + minor class additions. No JS, no new components. Desktop/tablet (≥768px) byte-identical.

### Changes (mobile-only)

1. **Filter button** — hide on mobile (non-functional; misleading to show).

2. **Breadcrumb** — currently `absolute top-[72px] px-12` (overlaps hero on phones). Mobile: `relative`, in-flow, `px-5`, tracking tightened. Same colours/links.

3. **Hero split-screen** — keep the SAME composition (image + text panel, eyebrow, H1, two lines, `bg-primary-container`). Mobile-only adjustments: `min-h` ~`360px`, text padding `p-6`, H1 `text-[1.75rem]` (from `text-4xl`), allow the `whitespace-nowrap` category list to wrap so it doesn't overflow. No new imagery — keeps `topcar/house.png`.

4. **Category bubbles** — keep the SAME secondary-filled pill design (`bg-secondary text-on-secondary rounded-full`, same links). Mobile: smaller padding (`px-5 py-3`, `text-xs`), horizontal snap-scroll row (one swipeable line) instead of wrapping awkwardly. Reuses exact bubble markup/styles at smaller scale.

5. **Magazine sections** — keep the SAME composition (eyebrow → H2 → body → EXPLORE link + image teaser, in the existing `flex-col md:flex-row` order). Mobile-only adjustments: drop the desktop-only `pl-[15%]`/`pl-[10%]` indents, H2 `text-[1.75rem]` (from `text-5xl`), body `text-sm`, section padding `px-5 py-8`, image heights capped ~`h-[220px]` (from `h-[405px]`/`h-[450px]`), `gap-12`→`gap-6`. Same images (`indoor.png`, `roll.png`, `kitchen.png`, `clean.png`), same blur-on-hover `roll-image-container` overlay.

6. **Teaser images** — make the whole `roll-image-container` a tappable card by wrapping it in the SAME `href` the adjacent EXPLORE link already uses (Home&Outdoor→`home-outdoor.html`, Kitchenware→`kitchenware.html`, Cleaning→`cleaning-tools.html`). Today these images aren't clickable despite `cursor:pointer`. Adds `active:scale-[0.98]` touch feedback. Desktop hover-blur overlay untouched.

7. **Rhythm** — consistent mobile gutters (`px-5`), standardised `py-8` section rhythm, capped heading sizes, tightened leading.

8. **Touch targets** — links/buttons ≥40px; `active:scale-95` feedback where missing.

### Reused (not redesigned)
- All images: `topcar/house.png`, `indoor.png`, `roll.png`, `kitchen.png`, `clean.png`
- Typography: font-headline (Manrope), font-body (Inter), same weights/tracking
- Colours: primary, secondary, primary-container, on-primary-container, surface
- Components: the bubble pill, the roll-image-container teaser, the EXPLORE arrow link, the breadcrumb
- Mobile nav (top header + bottom nav) — already complete, untouched

### Will NOT do
- Modify desktop/tablet (≥768px) — all overrides in `@media (max-width: 767px)`.
- Invent product grid / sort / filter functionality.
- Repurpose Filter button (hide only).
- Change backend, search, auth, cart, wishlist, product data, desktop animations.
- Duplicate components or rewrite working markup.
