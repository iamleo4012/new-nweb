## Plan: Premium Floating White Card — Mobile "Our Categories" Labels (Refined)

### File Changed
- `public/home.html` only

### Approach
The page has **two separate grids**: mobile (`md:hidden`, lines 786–868) and desktop (`hidden md:grid`, lines 870–952). Modifying the mobile grid's label containers has **zero effect on desktop**.

### Changes

#### A. Modify 5 Mobile Card Label Containers (HTML, lines 801–866)

For each of the 5 mobile cards, **replace the existing "Default Static Label" `<div>`** with a new floating white card container. The new structure per card:

```html
<!-- Before (example: Houseware, line 802) -->
<div class="absolute top-3 left-3 group-hover:opacity-0 transition-opacity duration-300">
  <h4 class="font-headline text-sm font-bold text-white tracking-widest uppercase">Houseware</h4>
</div>

<!-- After -->
<div class="absolute bottom-4 left-4 group-hover:opacity-0 transition-opacity duration-300 cat-label-card">
  <h4 class="cat-label-text">Houseware<br/><span>Equipment</span></h4>
</div>
```

**Text content per card (Title Case, not ALL CAPS):**
| Card | Line 1 | Line 2 |
|---|---|---|
| Houseware | Houseware | Equipment |
| Supermarket | Supermarket | Equipment |
| Warehouse | Warehouse | Equipment |
| Customized Packaging | Customized | Packaging |
| Cold Rooms | Cold Rooms | *(single line, no span)* |

**Position:** All cards normalized to `absolute bottom-4 left-4` (16px from edges) — consistent bottom-left placement.

**No arrow/chevron** — removed per refinement.

**Width:** No `max-width` — card naturally fits its content.

#### B. Add Mobile-Only CSS (inside existing `@media (max-width: 767px)` at ~line 317)

New rules appended **before the closing `}`** of the existing mobile categories media query:

```css
/* --- Premium floating label card (mobile only) --- */
.cat-label-card {
    display: inline-flex;
    align-items: center;
    background: #FCFCFB;
    border-radius: 20px;
    padding: 0.6rem 0.85rem;
    box-shadow:
        0 2px 8px rgba(0, 3, 8, 0.06),
        0 8px 24px rgba(0, 3, 8, 0.08);
}
html.dark .cat-label-card {
    background: rgba(255, 255, 255, 0.92);
    box-shadow:
        0 2px 8px rgba(0, 0, 0, 0.20),
        0 8px 24px rgba(0, 0, 0, 0.25);
}
.cat-label-text {
    margin: 0;
    font-family: 'Manrope', sans-serif;
    font-weight: 700;
    font-size: 0.8125rem;          /* 13px */
    line-height: 1.25;             /* comfortable line spacing */
    letter-spacing: 0.01em;        /* minimal tracking */
    text-transform: capitalize;
    color: #111d27 !important;      /* dark text, both lines */
    text-shadow: none !important;
    background: none !important;
}
.cat-label-text span {
    font-weight: 600;
    font-size: 0.75rem;            /* 12px */
    display: block;
    color: #111d27 !important;      /* same dark colour, not grey */
}
```

Key design decisions (refined):
- **Off-white background** `#FCFCFB` — warm, premium feel (not pure white)
- **20px border radius** — pill-like, Apple/Muji aesthetic
- **Soft layered shadow** — two layers: tight + diffuse for floating effect
- **Natural width** — `display: inline-flex` + no max-width = content-fitted
- **Both lines same colour** `#111d27` — no grey subtitle
- **Title Case** — `text-transform: capitalize` (HTML text written normally)
- **16px spacing** — `bottom-4 left-4` from card edges
- **No arrow** — minimal and clean
- **Dark mode** — semi-transparent white card, deeper shadows

#### C. Override existing mobile label typography rules

The existing CSS rules (lines 275–317) target `<h4>` broadly. The new `.cat-label-text` class rules use `!important` to override `text-shadow`, `color`, and `background`. Existing rules remain as fallback for any non-card labels.

### What is NOT Changed
- Desktop grid HTML (lines 870–952) — completely untouched
- Mobile grid layout (grid-cols-2, gap-2, card sizes, min-heights, row-span)
- Card dimensions, aspect ratios, overflow, rounded corners
- Images (src, class, filter, hover effects, grayscale)
- Hover overlay panels (remain `hidden` on mobile)
- Navigation, footer, or any other page section
- JavaScript (card click wiring unchanged)
