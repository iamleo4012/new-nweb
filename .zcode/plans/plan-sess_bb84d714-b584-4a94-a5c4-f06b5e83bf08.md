## Mobile-only redesign of `public/product view.html`

**One file changed: `public/product view.html`.** Desktop and tablet are 100% untouched — all changes are scoped inside `@media (max-width: 767px)` (CSS) plus one small JS block that self-disables above 767px. No element IDs or class contracts are renamed/removed, so every existing function (`updateMainImage`, `scrollRelated`, `toggleAccordion`, `addToCart`, `buyNow`, `toggleFavorite`, `copyProductLink`) keeps working unchanged.

### How it's done (3 additions, no rewrites)

**1. New mobile `<style>` block** (added once, scoped `@media (max-width: 767px)`) — pure layout/spacing/typography overrides, no design change:

- **Spacing & rhythm**: reduce `main` top padding (`pt-36`→flush), collapse `mb-24`/`mb-10`/`mt-20`/`py-10` to tight mobile rhythm; horizontal page padding `px-6`→`px-4`.
- **Hero → single column**: the `lg:grid-cols-12` already stacks on mobile; I tighten the gaps. Gallery moves above info (already `flex-col-reverse` on the gallery wrapper at `<md`, but the outer grid puts gallery first — confirmed correct order).
- **Gallery (swipe main + thumb strip)**: large main image `aspect-square`, full-width; thumbnails become a horizontal `overflow-x-auto hide-scrollbar` row below, snap-friendly. Add CSS so swiping the main image advances to next thumb (touch handlers added in JS block). Keep `.thumbnail-item` class + `updateMainImage()` reuse.
- **Info hierarchy**: title `text-4xl`→`text-2xl`, SKU/price spacing tightened, description clamped to 3 lines with a "More" expand (reuses `product-desc`).
- **CTA stacked full-width** (per user choice): Quantity stepper + Add to Cart in one full-width row, Buy Now full-width outline below, then a Wishlist + Share icon row — all within thumb reach, `min-h-12` touch targets.
- **Details accordion** (per user choice): on mobile, split into 2 accordion rows — **Description** (open by default) and **Specifications** (closed). Reuses the existing `.accordion-content`/`.expanded` CSS + `toggleAccordion` pattern. I'll add a second accordion (`<button onclick="toggleAccordion('specs-accordion')">`) wrapping the existing `#spec-grid`, and make `toggleAccordion` rotate the *clicked* row's icon (small, backward-compatible enhancement — current code hardcodes `#accordion-icon`, I'll generalize it to find the icon inside the clicked button so both rows animate). Desktop keeps its single expanded section.
- **Related products → horizontal swipe carousel** (the biggest fix): turn `#related-grid` into a horizontal `flex overflow-x-auto snap-x snap-mandatory` scroll container with `webkit-overflow-scrolling: touch`; each card `snap-start`, fixed mobile width (~`min-w-[70%]`), gap `1rem`. Hide the desktop arrow buttons on mobile (native swipe instead). Reuses the **identical** card markup the JS already injects (`data-product-card`, `aspect-[4/5]`, same image/title/price) — zero duplication. `scrollRelated()` already works on this container unchanged (it reads `#related-grid` + `[data-product-card]` width + 32 gap — I'll set the mobile gap to match, or override the step in the enhancement JS).
- No "Recently Viewed"/"You May Also Like" sections exist, so none are added (per exploration).

**2. Tiny mobile-only JS enhancement** (wrapped in `if (matchMedia('(max-width:767px)').matches)`):
- Swipe-on-main-image: track `touchstart`/`touchend` X delta on `#product-img-container`; on swipe left/right call `updateMainImage` with the next/prev `.thumbnail-item`'s image. No-op on desktop.
- Generalize `toggleAccordion` to rotate the icon *inside the clicked button* (so both Description and Specs rows animate their own chevron) while staying backward-compatible with the existing `description-accordion`/`#accordion-icon`.
- (Optional) adjust `scrollRelated` step to the mobile card width so the arrows — if a user still taps them — scroll correctly.

**3. No markup removal.** I only *add* a second accordion button+wrapper for specs (moving the existing `#spec-grid` inside it) and add `data-` hooks where needed. Every existing ID (`product-title`, `product-sku`, `product-price`, `product-desc`, `main-product-image`, `thumbnail-gallery`, `product-img-container`, `related-grid`, `spec-grid`, `description-accordion`, `accordion-icon`, `accordion-intro`, `bc-category`, `bc-line`, `qty`, `add-favorite-btn`, `fav-icon`, `share-product-btn`, `toast-container`) is preserved.
